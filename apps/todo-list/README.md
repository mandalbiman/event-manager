# Todo App

## Description
A simple, browser-based To-Do application where users can add, edit, delete, and mark tasks as complete. The app will use HTML, CSS, JavaScript, and jQuery with LocalStorage to save tasks even after the page is refreshed.

### Core Requirements:
1. Task Input & Display
    - A text input box to add a new task.
    - A button to add the task to the list.
    - Tasks should display in a list with the following:
      - Task name
      - A "Mark Complete" checkbox
      - A "Delete" button
      - An "Edit" option
2. Mark as Complete
    - Clicking the checkbox should visually mark the task as completed (e.g., line-through style).
3. Edit Tasks
   - Allow inline editing or a prompt to modify the task name.
4. Delete Tasks
   - Remove a task when the delete button is clicked.
5. Data Persistence
   - Store all tasks in LocalStorage so tasks remain after refreshing the browser.
